# Human feedback

One folder per test round. Each holds a self-contained `index.html` guide (open it in a browser — it works offline and sends nothing anywhere). After trying the app, press **Export ZIP** in the guide and drop the ZIP in the same round folder, e.g. `round-1-first-build/human-feedback-round-1-first-build.zip`. The answers live only in the browser tab until exported.

The workflow is in [docs/human-feedback-workflow.md](../docs/human-feedback-workflow.md).
