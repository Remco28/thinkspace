# Keyboard and mouse

Press `?` or `F1` in the app for the same sheet.

## Tools

| Key | Tool |
|---|---|
| `V` | Select |
| `A` | Arrow |
| `L` | Line |
| `R` | Rectangle |
| `E` | Ellipse |
| `T` | Text |
| `N` | Numbered marker |
| `P` | Pen |
| `H` | Highlighter |
| `X` | Remove marks |
| `C` | Cut out |

Hide details has a toolbar button and no key. Double-click a tool to keep it active until `Esc`.

## While drawing and moving

| Key | Effect |
|---|---|
| `Shift` | Straight angles, perfect squares, or lock to one axis |
| `Ctrl` | Ignore snapping |
| arrows | Nudge the selection. `Shift` nudges by 10 px, or one grid step when snapping |
| `[` `]` | Send backward or bring forward. Add `Ctrl` to go all the way |

## View

| Key | Effect |
|---|---|
| scroll wheel | Zoom at the pointer. `Shift` with the wheel pans |
| `Space` and drag, middle drag, right drag | Pan. A hint appears beside the zoom controls when the page is bigger than the window |
| `Ctrl+0` or `F` | Fit the page |
| `Ctrl+1` | Actual size |
| `G` | Show the grid |
| `Shift+G` | Snap to the grid |
| `F11` | Full screen, and back. It is also in the menu |

## Editing

| Key | Effect |
|---|---|
| `Ctrl+Z`, `Ctrl+Shift+Z` | Undo, redo |
| `Ctrl+C`, `Ctrl+X`, `Ctrl+D` | Copy, cut, duplicate |
| `Ctrl+V` | Paste. Asks where it should go |
| `Ctrl+Shift+V` | Paste into the collection |
| `S` | Take a screenshot: Thinkspace steps aside, you pick part of the screen, and it comes in like a paste |
| your choice | A screenshot from anywhere, set with **Screenshot shortcut…** in the menu |
| `Ctrl+L` | Lock the selection in place, or unlock it |
| `F2` | Rename the selection, or the layer you just clicked. On text, edit its words |
| `M` | Merge the selection into one image |
| `U` | Take a merged image apart. A small button under the selection does the same |
| right-click | Context menu for what is under the pointer |

In the Layers list, click a row and then use `↑` and `↓` to walk the list. `Shift` extends the selection, and `Shift`-click selects a run.

## Files and windows

| Key | Effect |
|---|---|
| `Ctrl+S` | Save |
| `Ctrl+O` | Open |
| `Ctrl+E` | Export PNG |
| `Ctrl+I` | Add image |
| `Ctrl+Shift+C` | Copy the page as an image |
| `Ctrl+Shift+N` | New window. It is also in the menu and in the dock icon's menu on Linux |
