# Critic B (Claude subagent, general-purpose — same model family as the author; Grok hung twice headless and opencode's free models hit their usage limit)

1. HIGH — clicking an attached end's handle without dragging can detach it: handle grab radius 9/zoom (_hitHandle, interactor.dart:168) vs object tolerance 4/zoom (objectsAt, controller.dart:856); the edge point sits on (or a border's width outside) the outline, so release "over a target" fails and C5 detaches. Pins would jump up to 9 px. Fix: release without movement restores the set-aside attachment; the attach test must count the border.
2. MEDIUM — the attach-target hit test is unspecified; objectsAt skips locked objects/layers (breaks C11); ShapeObject.hitTest is outline-only for unfilled shapes; ImageObject.hitTest ignores transparent pixels. Needs its own test: visible, locked allowed, box inside counts, topmost attachable wins.
3. MEDIUM — unmerge: parts' JSON keeps start/end; _unmergeInto gives parts new ids without remapping, so restored arrows snap to an outside object that still exists (against C10) and in-merge links are lost. Also _unmergeInto scales strokeWidth/width/fontSize by k but not borderWidth (B6).
4. MEDIUM — pushing the end out by w along the ray leaves it inside the border at an angle (w·cosθ); intersect with the outline grown by w.
5. MEDIUM — paintBounds = bounds inflated by w is too small for rotated objects (up to 1.41·w at 45°); compute from the rotated grown box; keep existing inflate margins on top.
6. MEDIUM — bending a connector does not follow the pointer: relink rewrites p1/p2 after _doBend sets mid, so the relative bend drifts; a body press jumps the middle to the press point. Keep the absolute middle during the drag, recompute bend after relink, apply a grab offset.
7. LOW — "relink does not run after _restore" is false: notifyListeners fires after undo/redo (showToast), abortEdit, restoreRecovery, loadProjectJson (after markSaved). Harmless only if relink is idempotent on consistent data; a dangling attachment in a file would be dropped after markSaved, leaving doc != disk with dirty false. State the invariant; run before markSaved; test that load and undo leave signature unchanged.
8. LOW — nudge/align/typed position on an attached line: relink pulls attached ends back, so arrow keys swing a one-end-free arrow instead of moving it.
9. LOW — shadow as a filled box shows through cut-outs, backdrop-less text and semi-transparent pictures; (0,3) offset in the object's frame points sideways/up on rotated objects.
10. LOW — B5: a mixed picture + text selection gets no Border row.
11. LOW (confirm with Frank) — by C4+C11 nearly every arrow drawn on a (locked) screenshot pins to it; by C6 dragging it then bends it: moving an arrow, today's commonest edit, stops working.
What to cut: drop the "_restore" exception in favour of the invariant in 7.
Sound: p1/p2 stored and real; one relink pass via notifyListeners and endEdit (no path found that bypasses it); id-map remapping at copy; freeing missing targets; freezing hidden ones.
