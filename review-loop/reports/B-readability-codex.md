## 1. Legibility and contrast

At 1×, the bold object name, layer icon, layer name, divider, and padlock are all identifiable. The bold name and lock are especially clear. The lighter layer name is readable, but its contrast is weak: sampling the tag gives about **2:1** for the layer text against the blue, versus about **4.5:1** for the white bold name.

The bold/light styling and layer icon make it clear which name belongs to the object and which to the layer. Brightening the layer name would make that distinction easier to scan without relying so much on weight.

## 2. Spacing

The padding and gaps look balanced overall. There is enough separation around the layer icon and divider, and the padlock has a distinct button area. Nothing looks cramped at true size.

## 3. Placement

The tag does not cover selection handles. In the awning sample, though, it overlaps the bakery sign and obscures part of its lettering. In the text-selection example, it covers part of a window edge; the rotate handle below it is close, but still distinct. In the other examples, the tag sits over blank canvas or picture area without a clear collision.

## 4. Ctrl+L message

The message is legible, with strong white-on-dark contrast. It overlaps the edge of the zoom control slightly, but does not cover its readout. It sits close to the bottom edge, yet remains fully visible.

## 5. Keep

Keep the bold object name, lighter layer name, layer icon, divider, and dedicated lock area: together they communicate the tag’s structure clearly. The one-time tip is easy to read and explains the shortcut directly.
